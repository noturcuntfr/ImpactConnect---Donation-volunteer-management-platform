# ImpactConnect 🌍 - Donation & Volunteer Management Platform

> Bridging the gap between donors, NGOs, and volunteers.

ImpactConnect is a web platform that makes donating as easy as ordering online. Donors can donate items, clothes, food, or money, NGOs can request what they need, and volunteers are assigned for pickup & delivery.

🔗 **Live Demo:** `https://your-render-link.onrender.com` (paste after deploy)
📂 **Repo:** https://github.com/noturcunfr/ImpactConnect---Donation-volunteer-management-platform

### ✨ Key Features

**For Donors:**
- Donate items with quantity, description & pickup address
- Donate money via UPI with purpose tracking
- Track donation status - Pending, Assigned, Delivered

**For NGOs:**
- View all incoming donations in real-time
- Request specific items
- Manage inventory

**For Volunteers:**
- Get assigned pickup tasks
- Update delivery status
- View assigned donations

**For Admin:**
- Central dashboard to manage all users
- Assign volunteers to donations
- Approve / manage NGOs and donors

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Core PHP
- **Database:** MySQL
- **Server:** Apache (XAMPP)
- **Deployment:** Render
